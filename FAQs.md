### **General notes (Do/Don’t)** 

|**Do**|**Don’t**|
|---|---|
|**Do** read the instructions carefully<br>before your first task.|**Don’t** enter the war room asking<br>someone to solve it for you; war rooms<br>are only for questions and technical<br>issues.|
|**Do** purchase both GPT Pro and<br>Claude Max 20x.|**Don’t** purchase only one of them.|
|**Do** contact support for payment<br>issues.|**Don’t** contact QMs for payment<br>issues, as they don’t have authority on<br>that.|
|**Do** run Gemini with the provided email<br>in the task.|**Don’t** use the one you created for<br>purchase; this will be used for the<br>second model, “GPT or Claude."|
|**Do** run one model at a time.|**Don’t** run both models at the same<br>time.|
|**Do** use the first prompt, as it is “just<br>copy and paste."|**Don’t** change anything in the first<br>prompt|
|**Do** mention the file name for the<br>model during the conversation to look<br>for it: "EX: Edit this file [name] from my<br>drive.”|**Don’t** upload it directly; let the model<br>search for it.|
|**Do** make at least 20 turns in the<br>conversation "prompt/response."|**Don’t** do fewer than 20 turns per<br>model.|
|**Do** copy the task ID and all turn links<br>aside in a sticky note or file.|**Don’t** forget that, in case any technical<br>issue happens, you need them, so you<br>don’t have to go over all this again.|
|**Do** change the files in the task if they<br>are incorrect to the correct files.|**Don’t** leave the links if they are wrong.|
|**Do** make several refreshes if the task<br>has missing parts or fails to load.|**Don’t** just skip the task; if the error is<br>still present, send the task ID to your<br>QM.|
|**Do** use the exact model version in the<br>task.|**Don’t** use the wrong one. If you can’t<br>find the model version in the task,<br>contact your QM in the war room to tell<br>you which version to use.|
|**Do** little changes to the rubric criteria<br>to adjust them if necessary. Also,<br>correct any misspellings or typos.|**Don’t** change the criteria entirely.|
|In **Aspirational** tasks. **Do** hydrate<br>both accounts before starting your<br>conversation.|**Don’t** hydrate only one of them.|
|**Do** confirm that you are using the<br>correct universe while hydrating. The<br>task universe may be different, so<br>change the universe accordingly. Point<br>to this thread:<br>https://community.outlier.ai/t/hydration-for-aspirational-tasks/2965777?u=ranaa_qmo_ar|**Don’t** use the wrong universe in the<br>hydration, or everything will be wrong.|
|**Do** familiarize yourself with the<br>universe, email, Drive, and GitHub; the<br>deliverable criteria; and the rubric<br>before continuing, so you can plan<br>your conversation.|**Don’t** just start the conversation<br>directly; this will make you miss task<br>requirements.|
|**Do** upload all generated files by the<br>model into the task, such as: “Doc,<br>PDF, XLS, image, flowchart in the form<br>of images, video, ..”<br>**_Remember:_** you should upload the<br>last version of the file, not all the<br>edited versions.|**Don’t** download or upload normal<br>information, such as tables, widgets,<br>information boxes, etc., as files. Do<br>not save this information as HTML and<br>upload it to the task, as this is<br>incorrect.|
