#### **FAQ’s** 

|Question 🤔|Answer ✅|
|---|---|
|**General questions**||
|🆕 I am new to the project. Where to start?|Start with the instructions and attend the first<br>onboarding session, then you can follow up on<br>all the changes and announcements in the daily<br>thread in the OC along with the war rooms. You<br>can also read it here [Information for newly allocated CBs](https://community.outlier.ai/t/information-for-newly-allocated-cbs/2970787/1)|
|🕚 I am running out of time! Can I have a<br>claim link to continue my task?|We are not providing claim links.<br>We cannot extend time on tasks. You must<br>submit by the expiration time. Please do not<br>post here asking us to extend, that is not<br>something we can do. If you are unable to<br>submit by expiration, you can refresh as soon<br>as it expires and hope that the same task is<br>served right back to you. But expiration time is<br>there for a reason. Please pay close attention to<br>it.<br>Please review the task expiry time before you<br>start the task, just to be sure that you have<br>enough time to complete it|
|⏲️ My task expired before I could complete it; I<br>spent a lot of time on it. Will there be any funds<br>for this time?|Please contact Support for this issue. Include<br>screenshots and the task ID in your ticket.|
|🤔 While creating the email ID on Gmail, the<br>“_” (underscore) is not accepted.|Please use a dot ‘.’ instead.<br>YourName.HoneybeeEvals@gmail.com|
|💬 Am I allowed to use **GPT**‑**6 Astra** with<br>medium thinking as Model B instead of Claude<br>Fable 5.1 for this task?|No, the task requirements are strict. You need<br>to use the correct model for each specific task.|
|🙂 How many types of tasks do we have?|We now have 3 types (workflows) of tasks:<br>**Honeybee Default** - our old taxonomy tasks,<br>**Honeybee V2** - the new taxonomy tasks. They<br>are the same as the old ones<br>(workspace-based only) but with the new<br>taxonomy and universes.<br>**Honeybee Agentic** - new taxonomy + new<br>types (`3p_one_way` `3p_two_way` and `1p`)|
|**Task workflow questions**||
|🤖 Which model should I use?|It’s still extremely important that you look at the<br>task requirements. In every task, both model<br>names are mentioned at the start of the task<br>under the “What You’ll Do” section, so please<br>check very carefully. Make sure you verify<br>which models are required for each task.|
|❓ Should I do the Probe test?|The Probe section is required ONLY for<br>**'Honeybee V2'** and **'Honeybee Agentic'**<br>workflow tasks. It is NOT required for<br>**‘Honeybee Default’** tasks! Please check your<br>task first to confirm which workflow you're<br>working on.|
|❗ How many turns does the task require?|For **Honeybee Default**, you still need to build a<br>conversation with **20+ turns**.<br>For **Honeybee V2** and **Honeybee Agentic**, the<br>requirements are different:<br>• The **maximum number of turns is 12**.<br>• The **minimum number of turns is 3 in**<br>**general**. You will be provided with an<br>**opening prompt** and **follow-up**<br>**prompts.** You must ask all of them.<br>**For example,** if your task includes an Opening<br>Prompt + 3 follow-up prompts, the minimum<br>required is **4 turns**.<br>However, if the target outcomes have not yet<br>been achieved, you must continue with<br>additional follow-up prompts until they are met.<br>**Important:** You must never exceed the<br>maximum limit of **12 turns** in total.|
|🤔 Can I edit later prompts?|**Yes,** you can rephrase them to make them<br>sound more natural, as long as you **do not**<br>**change the original meaning or intent**.|
|❗ Can I first emphasize the model’s reply and<br>then use the follow-up prompts provided in the<br>task?|**Yes**, you can. If the model asks any questions,<br>follow-ups, etc., we could answer them first and<br>then send later prompts.|
|❓ Does the order of the follow-up prompts<br>provided in the task matter?|**Yes.** The order is important. You must follow<br>the sequence provided, completing Turn 2<br>before moving on to Turn 3.|
|✅ The GTFA and known/not known<br>information are blank even though the<br>taxonomy says they should be prefilled!|According to the latest update, you are now<br>required to **fill in both fields yourself**. Please<br>follow the provided instructions carefully to<br>understand how to complete them correctly.|
|🥛 Sorry, I am new and can’t understand why<br>we made the hydration in the first place!|The **hydration process** is used to provide the<br>Gmail or Demo account with the specific data<br>the client wants to include in the task.<br>For example, this may include emails in Gmail,<br>files in Google Drive, or dates and events in<br>Google Calendar.<br>Because of this, we perform the hydration<br>process on both model accounts before starting<br>the conversation. This ensures that the **same**<br>**data is available in both accounts**, allowing<br>both models to process the task using identical<br>information.|
|💧 Hydration. My account is throwing an error<br>when I am trying to rehydrate it. How can I fix<br>this?|Please follow these steps [Information about Hydration](https://community.outlier.ai/t/hydration-for-aspirational-tasks/2965777). If that doesn’t work, go to the War<br>Room or Outlier Community, and a QM will help<br>reset it for you.|
|🤔 What is the correct format for the uploaded<br>files?|The format of uploaded files:<br>• For files: My Drive / Folder 1/ …../ Folder<br>n/ file_name<br>• For calendar events: Calendar / Date /<br>Event_name.<br>• For emails: Gmail / Inbox / Sender or<br>receiver’s name/ Subject / First some<br>words of the email.<br>• For GitHub: GitHub / Given Path (Given<br>Path is the path for the file, whenever<br>you locate a file in GitHub, its path is<br>visible there, right on the top below the<br>navbar.)|
|📄 Gemini is refusing to connect to my Google<br>Drive even though I know it can.|Check the connectors. Try using the command<br>@Google Drive to force the connector to work.|
|📦 Gemini is exporting the trajectory PDF<br>starting from the point where a conversation<br>was continued, rather than including the full<br>conversation.|Export the trajectory to a .docx and then print it<br>to a PDF from there.|
|🔄 How can I convert the GPT/Claude model<br>chat to a PDF?|You can use this tool for GPT.<br>[https://chromewebstore.google.com/detail/chatgpt-exporter-save-cha/ploaaddkflkapjfbfapmkmkefigedefp?utm_source=item-share-cb&pli=1](https://chromewebstore.google.com/detail/chatgpt-exporter-save-cha/ploaaddkflkapjfbfapmkmkefigedefp?utm_source=item-share-cb&pli=1)<br>Use this one for Claude.<br>[https://chromewebstore.google.com/detail/ai-chat-exporter-save-cla/elhmfakncmnghlnabnolalcjkdpfjnin?utm_source=item-share-cb](https://chromewebstore.google.com/detail/ai-chat-exporter-save-cla/elhmfakncmnghlnabnolalcjkdpfjnin?utm_source=item-share-cb)<br>These are the ONLY tools approved by the<br>Project Team. For reasons of security, ONLY<br>use tools approved by the PT!|
|📖 The rubric is not so accurate, what should I<br>do?|You can now edit the rubric and make small<br>changes, not totally change the criteria; just<br>adjust it accordingly.|
|📂 The task provides broken links to the files. I<br>opened the file, and it is not readable. How do<br>I locate the file?|Use this approach [How to handle Input files for aspirational tasks if the path is not correct](https://community.outlier.ai/t/temporary-workaround-on-how-to-handle-input-files-for-aspirational-tasks/2962825/1). ### **General notes (Do/Don’t)** 

|**Do**|**Don’t**|
|---|---|
|**Do** read the instructions carefully<br>before your first task.|**Don’t** enter the war room asking<br>someone to solve it for you; war rooms<br>are only for questions and technical<br>issues.|
|**Do** contact support for payment<br>issues.|**Don’t** contact QMs for payment<br>issues, as they don’t have authority on<br>that.|
|**Do** run one model at a time.|**Don’t** run both models at the same<br>time.|
|**Do** use the first prompt, as it is “just<br>copy and paste."|**Don’t** change anything in the first<br>prompt|
|**Do** mention the file name for the<br>model during the conversation to look<br>for it: "EX: Edit this file [name] from my<br>drive.”|**Don’t** upload it directly for aspirational<br>tasks; let the model search for it.|
|**Do** copy the task ID and all turn links<br>aside in a sticky note or file.|**Don’t** forget that, in case any technical<br>issue happens, you need them, so you<br>don’t have to go over all this again.|
|**Do** make several refreshes if the task<br>has missing parts or fails to load.|**Don’t** just skip the task; if the error is<br>still present, send the task ID to your<br>QM.|
|**Do** use the exact model version in the<br>task.|**Don’t** use the wrong one. If you can’t<br>find the model version in the task,<br>contact your QM in the war room to tell<br>you which version to use.|
|**Do** little changes to the rubric criteria<br>to adjust them if necessary. Also,<br>correct any misspellings or typos.|**Don’t** change the criteria entirely.|
|In **Aspirational** tasks. **Do** hydrate<br>both accounts (demo and honeybee)<br>before starting your conversation.|**Don’t** hydrate only one of them.|
|**Do** confirm that you are using the<br>correct universe while hydrating. The<br>task universe may be different, so<br>change the universe accordingly. Point<br>to this thread:<br>[https://community.outlier.ai/t/hydration-for-aspirational-tasks/2965777?u=ranaa_qmo_ar](https://community.outlier.ai/t/hydration-for-aspirational-tasks/2965777?u=ranaa_qmo_ar)|**Don’t** use the wrong universe in the<br>hydration, or everything will be wrong.|
|**Do** familiarize yourself with the<br>universe, email, Drive, and GitHub; the<br>deliverable criteria; and the rubric<br>before continuing, so you can plan<br>your conversation.|**Don’t** just start the conversation<br>directly; this will make you miss task<br>requirements.|
|**Do** upload all generated files by the<br>model into the task, such as: “Doc,<br>PDF, XLS, image, flowchart in the form<br>of images, video, ..”<br>**_Remember:_** you should upload the<br>last version of the file, not all the<br>edited versions.|**Don’t** download or upload normal<br>information, such as tables, widgets,<br>information boxes, etc., as files. Do<br>not save this information as HTML and<br>upload it to the task, as this is<br>incorrect.|
